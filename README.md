# KIPRIS 지식재산정보 상표·로고 중복 검증 대시보드

공공데이터포털의 **지식재산처_KIPRIS_지식재산정보 검색서비스(특허청 Open API)**를 활용하여, 창업 전 새로운 **가게명(상호), 브랜드명, 로고, 이미지**가 이미 등록되어 있는지 여부와 상표권 침해 위험도를 사전에 진단해 주는 통합 대시보드 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **가게명 (문자 상표) 위험도 진단**
   - 상표명 및 업종(NICE 상품분류 43류/35류/30류 등)별 검색
   - 특허청 권리 상태별(등록, 출원, 거절, 소멸) 자동 분류
   - **위험도 신호등**:
     - 🔴 **위험 (DANGER)**: 동일 업종에 이미 유효한 등록 상표 존재 (침해 소송 위험)
     - 🟡 **주의 (WARNING)**: 현재 특허청에서 심사진행 중인 출원 건 존재
     - 🟢 **안전 (SAFE)**: 미등록 신규 명칭 또는 기존 건 모두 거절/소멸
2. **로고·이미지 (도형/디자인) 스크리닝**
   - 로고 이미지 업로드 및 비엔나 도형분류(Vienna Code) 키워드 검색
   - 유사 도형상표 및 등록 디자인 공보 도면 비교
3. **마이폴더 (관심 보관함)**
   - 비교 검토 중인 상표 후보군을 로컬 및 데이터베이스에 체계적으로 북마크
4. **시뮬레이션(Mock) 모드 지원**
   - 공공데이터포털 API 키가 아직 발급되지 않았더라도 풍부한 샘플 데이터로 즉시 모든 기능 테스트 가능

## 🚀 빠른 시작 가이드 (초보자용)

### 1. 환경 설정 (.env)
이미 기본 설정이 완료되어 있습니다. 만약 공공데이터포털 또는 KIPRISPlus에서 발급받은 실제 API 키가 있으시다면 `.env` 파일을 열어 수정하세요:

```env
# 실제 API 키가 있는 경우
KIPRIS_API_KEY=발급받은_서비스키_입력
KIPRIS_USE_MOCK=false

# API 키가 없거나 테스트 중인 경우 (기본값)
KIPRIS_USE_MOCK=true
```

### 2. 대시보드 서버 실행
터미널에서 아래 명령어를 입력합니다:

```bash
python3 server.py
```

### 3. 브라우저 접속
웹 브라우저(크롬, 사파리 등)를 열고 아래 주소로 접속하세요:
👉 **http://localhost:8000**
